# Integrated Individual Consent Wizard

This feature keeps the Consent Templates two-button chooser and turns **New Individual Consent** into one continuous workflow:

1. Build a new reusable template.
2. Automatically publish version 1.
3. Enter the first signer's details and optional deadline.
4. Create the individual consent record.
5. Open the existing evidence page with Copy Link, Email and WhatsApp sharing.

The public-consent button and signing-station workflow are not changed.
