# Consent Template UI Polish

This update keeps the integrated individual-consent workflow while refining the template and signer interfaces.

## Changes

- Consent Templates opens the Manage Templates page by default.
- One New Consent button opens the Individual/Public chooser.
- Template action buttons use a consistent three-column alignment.
- The special Reference Number shortcut is removed; reference data can be created as a normal custom field.
- Empty additional-field panels are hidden from signers while the Continue to Signature action remains available.
- Share via email is always shown before Share on WhatsApp.
- Static template information uses Signer Name rather than patient-oriented terminology.

No database migration is required.
